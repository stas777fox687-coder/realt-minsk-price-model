# Цены на квартиры в Минске: сбор данных и модели

Проект от начала до конца: парсер объявлений Realt.by, очистка данных и сравнение четырёх моделей регрессии, которые предсказывают цену квартиры в долларах.

## Результаты

Выборка: 2400 объявлений о продаже квартир в Минске (собраны 10.11.2026), после очистки 2388. Разбиение 80/20, `random_state=42`.

| Модель | MAE, $ | RMSE, $ | R² |
|---|---|---|---|
| Baseline (среднее) | 60 944 | 91 922 | 0,00 |
| LinearRegression | 30 105 | 48 042 | 0,73 |
| Ridge | 29 806 | 47 798 | 0,73 |
| **RandomForest** | **23 820** | **43 559** | **0,77** |

Выводы:

- Случайный лес ошибается в среднем на $24 тыс., а предсказание «всегда средняя цена» на $61 тыс. Ошибка меньше в 2,5 раза.
- Лес лучше линейных моделей, вероятно, из-за нелинейных зависимостей цены от признаков.
- RMSE заметно больше MAE: на дорогих квартирах модель ошибается сильнее.

## Данные и признаки

- Источник: публичные объявления Realt.by о продаже квартир в Минске. Парсер читает данные страницы (JSON внутри `__NEXT_DATA__`), паузы между запросами 1–2 секунды.
- Признаки: общая, жилая площадь и площадь кухни, число комнат, этаж, этажность, год постройки, минуты до метро, координаты, расстояние до центра (считается по координатам), код типа дома, код ремонта, код балкона, станция метро.
- Цель: цена в USD.
- Цена за квадратный метр в признаки не включена, так как она считается из цены и дала бы модели ответ.

## Запуск

```
pip install -r requirements.txt
python scraper.py --url "<адрес списка с фильтрами>" --probe   # проверка полей
python scraper.py --url "<адрес списка с фильтрами>" --pages 80
python train.py
```

Файл `apartments.csv` в репозиторий не включён: его можно собрать самостоятельно командами выше.

## Ограничения

- В объявлениях указана **цена предложения**, а не цена сделки. Реальные цены продажи обычно ниже.
- Данные собраны за один день и отражают только квартиры, выставленные на момент сбора. Парсер остановился по лимиту в 80 страниц, часть объявлений могла остаться вне выборки.
- Типы дома, ремонта и балкона на сайте закодированы числами. Что означает каждый код, неизвестно, поэтому модель использует их как категории.
- Метрики получены на одном разбиении данных. Кросс-валидация не проводилась.
- Название района города в данных отсутствует, поэтому местоположение описывают координаты, расстояние до центра и станция метро.
